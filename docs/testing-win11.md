# Windows 11 手动验收清单

SnipStack 的核心功能(剪贴板监听、全局热键、混合 DPI 框选)只能在真实 Win11
环境验证。每个里程碑节点在 VM 里过一遍基础清单;**发布前必须在实体多显示器
机器上过一遍 DPI 矩阵**(VM 的显示器模拟会失真)。

## 环境准备

```bash
pnpm install
pnpm fetch:ocr-models
pnpm build:icon
pnpm tauri dev
```

## 基础清单(每次迭代)

- [ ] 应用启动进托盘,剪贴板窗口 Alt+C 可呼出/隐藏
- [ ] 复制文本/图片,历史列表实时出现;搜索中文关键词(≥2 字)可命中
- [ ] **Alt+S 框选取字**:覆盖层出现无白闪;拖拽框选中英混排文字 → 剪贴板得到正确文本;剪贴板窗口出现字数 toast
- [ ] 框选一个屏幕上的二维码 → 直接得到码值(而非 OCR 文本)
- [ ] Esc 与右键均能取消框选;热键连按不产生重复覆盖层
- [ ] 复制一张含文字的图片,等约 2–5 秒,按图中文字搜索能命中该图片条目
- [ ] 截屏取字的截图条目出现在历史里,按识别文字可搜到
- [ ] KeePass/KeePassXC/1Password 复制密码 → 历史**不**出现该条目
- [ ] 设置「截屏取字」页:改换行模式(合并后中文续行无空格)、关闭自动复制/存历史均生效;改热键后立即生效,与 Alt+C/Alt+X 冲突时有提示
- [ ] 托盘菜单「截屏取字」入口可用

## 混合 DPI 矩阵(发布前,实体机)

对每个组合执行:主/副屏各做一次框选,验证 ①覆盖层完整铺满该屏无错位、
②选区裁剪内容与所见完全一致(边缘 1–2px 内)、③识别文本正确。

| # | 主屏 | 副屏 | 备注 |
|---|---|---|---|
| 1 | 1080p @ 100% | — | 基线 |
| 2 | 4K @ 150% | — | 单屏高缩放 |
| 3 | 4K @ 150% | 1080p @ 100% | 混合缩放,重点 |
| 4 | 1080p @ 100% | 4K @ 150% | 副屏为高缩放 |
| 5 | 任意 | 任意,副屏在主屏**左侧**(负坐标) | 虚拟屏原点不在 (0,0) |
| 6 | 会话中途改缩放比例 | — | 改完再 Alt+S,覆盖层应适配新几何 |

若出现选区错位:记录两屏分辨率/缩放/相对位置与偏移量级,回报后切换
原生 Win32 覆盖层方案(Plan B,见计划文件)。

## 已知限制(v0.1 接受)

- 跨显示器的单次框选不支持(每次框选限一个屏)。
- 向管理员权限窗口的自动粘贴不涉及(本产品仅复制,不模拟粘贴)。
- 精确全屏覆盖层理论上可能触发 Windows 专注助手(勿扰);如实测出现,
  在此记录并评估上游 preview 同款的 -1px 规避。
