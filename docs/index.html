SnipStack

框选屏幕任意文字 · 留住复制过的一切

下载 SnipStack

Windows 11 · 免费 · 无广告 · 所有版本

三步装好

1点上面的按钮下载,打开下载好的 SnipStack…setup.exe。
2如果 Windows 弹出蓝色的"已保护你的电脑",别慌——点「更多信息」,再点「仍要运行」就好。(这只是因为我们还没买微软的签名证书。)
3装好后它住在右下角托盘里。按 Alt+S 框选屏幕上的文字,按 Alt+C 翻你复制过的所有东西。
你复制的一切只保存在你自己的电脑上,不上传、无账号、无广告。
